# 风格样例索引

`assets/examples/` 中的 6 张图片用于低频视觉校准。它们是本技能默认 3D IP 编辑型插画的唯一画风与样式来源，不是文章主题模板。外部技能或仓库不得补充视觉特征，只能参考其文件组织方式。

## 使用方式

1. 每次只选择 1–2 张与目标资产最接近的样例。
2. 同时提供 `assets/default-ip-reference.png` 锁定角色身份。
3. 在提示词中声明：样例只约束媒介、光线、留白、标题层级、强调色和信息密度。
4. 不复制样例的标题、服装题材、道具组合、具体界面、文章结论或构图。
5. 用户提供新的正向案例时，优先使用用户案例；不要自动覆盖内置样例。

## 仅从本次 6 张成图提炼的固定特征

- 大头玩偶 IP 约占画面 25%–40%，通常位于一侧并承担判断、指向、检查或承重动作。
- 空间是安静的灰白摄影棚或微缩展陈空间；背景不讲故事，只提供秩序与呼吸感。
- 主体物件具备真实材料触感：针织、纸样、金属、木衣架、玻璃或磨砂亚克力。
- 标题使用深色粗体或宋黑混合的编辑排版；强调词或警告只用一个低饱和红色。
- 正文图可以带 3–5 个极短标签，但首先依靠物理关系讲清楚，不依赖读完所有字。
- 画面精致、克制、略带冷感；不卖萌，不用夸张表情，不做热闹商业海报。
